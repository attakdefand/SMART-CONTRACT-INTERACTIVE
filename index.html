About This Project

This project contains a comprehensive catalog of 146 tests for interacting with smart contracts, organized by category and sub-type. The tests cover various aspects of smart contract security, functionality, and best practices.

Each test file contains detailed steps to perform the test, key assertions to verify, and suggested tools. These tests can be used as a checklist when developing, auditing, or testing smart contracts to ensure comprehensive coverage of potential issues and edge cases.
