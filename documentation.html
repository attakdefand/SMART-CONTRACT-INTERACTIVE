Project Overview

This project contains 146 comprehensive tests for interacting with smart contracts, organized by category and sub-type. The tests cover various aspects of smart contract security, functionality, and best practices.

Usage Guide

Each test file contains:

  • Test name - Descriptive title of the test
  • Interaction type - Type of interaction (read, write, event, etc.)
  • Detailed steps - Step-by-step procedure to perform the test
  • Key assertions - Expected outcomes to verify
  • Suggested tools - Recommended tools for executing the test
  • Additional notes - Any additional information or considerations

How to Use the Tests

  1. Browse the src/ directory to find tests relevant to your smart contract
  2. Open a test file to view the detailed steps and assertions
  3. Follow the procedure to execute the test on your smart contract
  4. Verify that the key assertions are met
  5. Document any issues or deviations from expected behavior
